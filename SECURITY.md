# Política de seguridad

## Reporte de vulnerabilidades

Si detectas una vulnerabilidad de seguridad en este repositorio o en `christopher.com.mx`, por favor **no abras un issue público**.

Envía los detalles directamente a:

- **Correo:** [hola@christopher.com.mx](mailto:hola@christopher.com.mx)

Incluye una descripción clara del problema, los pasos para reproducirlo y el posible impacto para poder revisarlo y corregirlo a la brevedad.
