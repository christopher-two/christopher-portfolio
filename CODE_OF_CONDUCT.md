# Código de conducta

## Compromiso

Para fomentar un entorno abierto y respetuoso, nos comprometemos a mantener la participación en este repositorio libre de acoso, discriminación o ataques personales, sin importar nivel de experiencia, identidad o procedencia.

## Comportamiento esperado

- Comunicación clara, constructiva y respetuosa en issues y Pull Requests.
- Aceptación de críticas técnicas enfocadas en el código y el producto.
- Respeto por la privacidad de colaboradores y usuarios.

## Contacto

Cualquier incidente puede reportarse de forma confidencial a [hola@christopher.com.mx](mailto:hola@christopher.com.mx).
